# 🚗 Smart Parking System using 8051

## 📌 Project Overview
This project simulates a smart parking management system using the AT89C51 microcontroller.

The system automatically updates available parking slots using entry and exit buttons and displays the parking status on a 16x2 LCD.

---

## 🛠 Software Used
- Keil µVision
- Proteus 8 Professional

---

## 🔧 Components Used
- AT89C51 Microcontroller
- 16x2 LCD
- Push Buttons
- Crystal Oscillator
- Capacitors
- Resistors

---

## ⚙ Working Principle
- Entry button decreases available slots
- Exit button increases available slots
- LCD continuously displays slot availability
- When slots become zero:
  `PARKING FULL` is displayed
